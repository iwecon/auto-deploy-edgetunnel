把 EdgeTunnel 部署，
收束成一条命令。

验证凭据、准备 KV、上传固定版本 Worker，
并在订阅真正可用后再交付结果。

开始安装 查看源码
$ curl -fsSL https://raw.githubusercontent.com/iwecon/auto-deploy-edgetunnel/main/install.sh | sh
✓ edgetunnel installed
凭据验证 准备 KV 上传 Worker 验证后交付

为最小依赖而生。

一个 Swift 可执行文件。没有运行时包袱，没有把密钥交给第三方服务。

# 依赖
$ which swift          swift
$ edgetunnel --help    ready

从凭据，到可验证的订阅。

验证 Token 准备 KV 配置 Pages 上传 Worker 校验订阅

只有订阅内容、UUID 与 TLS WebSocket 节点都通过验证，才算完成。

安全不是一句口号，是边界。

Token 不落盘。

API Token 只存在于本次进程；成功输出与状态文件都不会包含它。

状态可恢复。

UUID、管理密码与远端资源 ID 原子写入受保护的状态文件，重跑不会随意换凭据。

固定 Worker commit 与 SHA-256；上传前强制校验。

你仍需知道

管理页面由上游远端动态提供；第三方节点地址也可能变化。
工具会明确这条边界，不把它包装成绝对安全。

选择你的入口。

这是原生 Swift CLI。使用可审计的安装路径，不套一层多余的运行时。

Homebrew

brew install --HEAD https://raw.githubusercontent.com/iwecon/auto-deploy-edgetunnel/main/Formula/edgetunnel.rb

macOS / Linux

curl -fsSL https://raw.githubusercontent.com/iwecon/auto-deploy-edgetunnel/main/install.sh | sh

Windows PowerShell

irm https://raw.githubusercontent.com/iwecon/auto-deploy-edgetunnel/main/install.ps1 -OutFile install.ps1; .\install.ps1

源码

git clone https://github.com/iwecon/auto-deploy-edgetunnel && cd auto-deploy-edgetunnel && swift run edgetunnel

把结果交给验证，而不是运气。
